# Story 4.6 — Customer Profile Management

## Status
ready-for-dev

## Description
Allow customers to view and update their profile (full name, phone) and manage saved delivery addresses. A default address pre-fills the checkout delivery form. Backend exposes `GET /profile` and `PATCH /profile` routes, plus full CRUD for the `addresses` table.

## Acceptance Criteria
- [ ] `GET /profile` backend route implemented, requires `authenticate`, returns current user's profile
- [ ] `PATCH /profile` backend route implemented, requires `authenticate`
- [ ] `PATCH /profile` accepts `{ full_name?, phone? }` and validates phone with `isValidCameroonPhone()`
- [ ] `PATCH /profile` updates the `profiles` table and returns the updated profile
- [ ] `UpdateProfileRequest` interface added to `packages/shared/types/user.ts`
- [ ] Backend routes registered in `app.ts`
- [ ] `pages/account/profile.vue` created with correct `definePageMeta`
- [ ] Profile form has fields: Full name (editable), Phone (validated on blur), Email (read-only from Supabase auth)
- [ ] On submit: calls `PATCH /profile` with auth token
- [ ] On success: toast "Profile updated successfully" and `authStore.fetchProfile()` called to refresh store
- [ ] On error: field-level errors displayed
- [ ] `pages/account/addresses.vue` created with correct `definePageMeta`
- [ ] Addresses page lists saved addresses from the `addresses` table
- [ ] Add new address form with fields: full_name, phone, city, address, region (uses `CAMEROON_REGIONS`)
- [ ] "Set as default" button marks an address as default
- [ ] "Delete" button removes an address
- [ ] Default address pre-fills `state.deliveryData` in `useCheckout` when user lands on checkout

**`addresses` table** (create migration if not present):
```sql
create table addresses (
  id uuid primary key default gen_random_uuid(),
  user_id uuid references auth.users(id) on delete cascade not null,
  full_name text not null,
  phone text not null,
  city text not null,
  address text not null,
  region text not null,
  is_default boolean default false not null,
  created_at timestamptz default now() not null
);
alter table addresses enable row level security;
create policy "Users manage own addresses" on addresses
  for all using (auth.uid() = user_id);
```

When setting an address as default, first set `is_default = false` for all other user addresses, then set `is_default = true` for the selected one.
