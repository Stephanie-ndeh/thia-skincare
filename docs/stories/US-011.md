# Story 2.3: Product Listing Page (PLP) with Filtering and Sorting

**Status:** ready-for-dev
**Phase:** 2 — Core Shop
**PRD Reference:** FR-2.3, FR-2.4, FR-2.10, FR-2.12

## Story

As a guest visitor,
I want to filter and sort products on the listing page,
so that I can quickly find products that match my preferences and budget.

## Acceptance Criteria

1. **URL:** `/categories/[slug]` serves as the PLP (built in US-010). This story adds filtering, sorting, view toggle, and pagination on top of that page. All filter/sort state is reflected in the URL query string so filters survive page refresh and can be shared.
2. **Filter by category** — when on `/categories` index or a specific category page, a sidebar/filter panel allows selecting any of the 9 categories. On `/categories/[slug]`, the current category is pre-selected.
3. **Filter by price range** — two number inputs: "Min price (XAF)" and "Max price (XAF)". Applied on "Apply" button click. Cleared by emptying both fields.
4. **Sort options** — dropdown or radio group: "Newest" (default), "Price: Low to High", "Price: High to Low", "Best Rated". Changing sort re-fetches/re-sorts immediately.
5. **Grid / List view toggle** — two icon buttons: grid icon (default) and list icon. Grid view: `ProductCard` grid. List view: horizontal product rows with image left, details right. Toggle persists in `localStorage`.
6. **Pagination** — display 12 products per page. Pagination controls: prev/next buttons + page numbers. URL reflects page: `?page=2`.
7. **Result count** — "Showing X–Y of Z products" above the grid.
8. **Mobile filter** — on mobile, filters collapse into a slide-in drawer (shadcn `Sheet`) triggered by a "Filters" button. Desktop: filters shown in a left sidebar.
9. **Active filters** — display applied filters as removable tags/chips above the grid (e.g., "Category: Serums ×", "Max: 15,000 XAF ×").
10. **Empty state** — if no products match filters: "No products match your filters." + "Clear filters" button.
