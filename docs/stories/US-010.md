# Story 2.2: Category Pages

**Status:** ready-for-dev
**Phase:** 2 — Core Shop
**PRD Reference:** FR-2.2, FR-2.12

## Story

As a guest visitor,
I want to browse all product categories and navigate into each one,
so that I can discover what types of products Thia sells and start narrowing down my choices.

## Acceptance Criteria

1. **Category index page** (`/categories`) — displays all 9 categories in a responsive grid. Each card shows: category image, category name, product count (count of published products in that category), links to `/categories/[slug]`. Renders SSR.
2. **Category detail page** (`/categories/[slug]`) — displays: category hero section (name + description + optional image), then a product grid filtered to that category. Products fetched server-side.
3. **Category hero** — full-width banner-style section with the category's name as a large heading and description as a subtitle. Uses category `image_url` if present as a subtle background.
4. **Breadcrumb** on `/categories/[slug]`: `Home > [Category Name]` — clicking "Home" links to `/`.
5. **Empty state** — if a category has no published products: "No products in this category yet. Browse all products →" linking to `/categories`.
6. **SEO** — `/categories` has generic title/meta. `/categories/[slug]` uses `useHead()` with category name and description. Both render SSR.
7. **404 handling** — if `[slug]` doesn't match any category, call `createError({ statusCode: 404, message: 'Category not found' })`.

## Files to Create / Modify

**Create:**
- `pages/categories/index.vue` — all categories listing
- `pages/categories/[slug].vue` — single category with products
- `components/layout/Breadcrumb.vue` — reusable breadcrumb component

**Reuse (from US-009):**
- `components/product/ProductCard.vue`
- `components/product/ProductGrid.vue`

## Implementation Tasks

- [ ] **Task 1: Create `Breadcrumb.vue`** (AC: #4)
  - [ ] Props: `items: Array<{ label: string, href?: string }>`
  - [ ] Renders a `<nav aria-label="breadcrumb">` with items separated by `/` or `›`
  - [ ] Last item is not a link (current page)
  - [ ] Uses Lucide `ChevronRight` as separator

- [ ] **Task 2: Build `pages/categories/index.vue`** (AC: #1, #6)
  - [ ] `definePageMeta({ layout: 'default' })`
  - [ ] Fetch: `useAsyncData('categories-with-count', () => supabase.from('categories').select('id,name,slug,description,image_url,display_order, products(count)').order('display_order').then(r => r.data))`
    - Note: Supabase supports `products(count)` to get aggregate count with a filter on `is_published=true` via a separate query if needed. Alternatively fetch categories, then count separately.
  - [ ] Render category cards in responsive grid: 2 cols mobile, 3 tablet, 3 desktop
  - [ ] Each card: `NuxtImg` (category image or placeholder), category name, product count badge e.g. "12 products"
  - [ ] `useHead()`: title "Shop by Category — Thia", meta description

- [ ] **Task 3: Build `pages/categories/[slug].vue`** (AC: #2–#5, #6, #7)
  - [ ] `definePageMeta({ layout: 'default' })`
  - [ ] Fetch category by slug: `useAsyncData(\`category-\${slug}\`, () => supabase.from('categories').select('*').eq('slug', slug).single().then(r => r.data))`
  - [ ] If `!category`, call `createError({ statusCode: 404 })`
  - [ ] Fetch products for category: `useAsyncData(\`products-\${slug}\`, () => supabase.from('products').select('id,name,slug,categories(name),product_variants(price),product_images(url,is_primary)').eq('category_id', category.id).eq('is_published', true).order('created_at', { ascending: false }).then(r => r.data))`
  - [ ] Render `Breadcrumb` with `[{ label: 'Home', href: '/' }, { label: category.name }]`
  - [ ] Render category hero: `<h1>` with category name, `<p>` with description
  - [ ] Render `ProductGrid` with fetched products
  - [ ] If `products.length === 0`, render empty state message
  - [ ] `useHead()`: `title: \`${category.name} — Thia\``, `meta: [{ name: 'description', content: category.description }]`
