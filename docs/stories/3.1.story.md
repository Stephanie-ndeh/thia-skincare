# Story 3.1 — Shipping Zones & Rates (Backend)

## Status
ready-for-dev

## Description
Implement two backend routes that expose shipping zone data and calculate shipping costs for a given city and order subtotal. The calculation applies free-shipping thresholds and falls back to a default rate when no zone is matched.

## Acceptance Criteria
- [ ] `GET /shipping/zones` returns all active zones ordered by `display_order`
- [ ] `GET /shipping/zones` response shape: `{ data: ShippingZone[] }`
- [ ] `POST /shipping/calculate` accepts `{ city: string, subtotal: number }` in the request body
- [ ] City matching is case-insensitive against zone city lists
- [ ] If `subtotal >= zone.free_threshold` and threshold > 0, returned rate is `0` and `is_free` is `true`
- [ ] If no zone matches the city, rate defaults to `2500` XAF and `zone_name` is `'Standard'`
- [ ] Response shape: `{ data: ShippingCalculateResponse }` with `rate`, `zone_name`, `is_free`
- [ ] Both routes registered in `src/app.ts`
- [ ] `ShippingZone` and `ShippingCalculateResponse` exported from `packages/shared/types/shipping.ts`

## Technical Notes

**New shared types** — `packages/shared/types/shipping.ts`:
```ts
export interface ShippingZone {
  id: string
  name: string
  cities: string[]
  rate: number           // XAF integer
  freeThreshold: number  // 0 = never free
  displayOrder: number
  isActive: boolean
}

export interface ShippingCalculateRequest {
  city: string
  subtotal: number
}

export interface ShippingCalculateResponse {
  rate: number
  zoneName: string
  isFree: boolean
}
```

**Route file**: `apps/backend/src/routes/shipping/index.ts`

**Calculate logic**:
1. Lowercase `city` from body
2. Query `shipping_zones` where `is_active = true`, ordered by `display_order`
3. Find first zone whose `cities` array contains the lowercased city
4. If found: check `subtotal >= zone.free_threshold && zone.free_threshold > 0` → rate = 0, is_free = true; else rate = zone.rate, is_free = false
5. If not found: rate = 2500, zone_name = 'Standard', is_free = false

**Registration**: `fastify.register(shippingRoutes)` in `src/app.ts`
