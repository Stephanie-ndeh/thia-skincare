# Story 2.4: Product Detail Page (PDP)

**Status:** ready-for-dev
**Phase:** 2 — Core Shop
**PRD Reference:** FR-2.5, FR-2.6, FR-2.7, FR-2.11, FR-2.12

## Story

As a guest or shopper,
I want to see complete product information — images, variants, price, stock, and reviews —
so that I can make an informed purchase decision and add the right variant to my cart.

## Acceptance Criteria

1. **URL:** `/products/[slug]`. Renders SSR with full HTML for SEO. Returns 404 if slug not found.
2. **Image gallery** — primary image displayed large (left column desktop, top mobile). Thumbnails below (desktop) or below main (mobile). Clicking thumbnail swaps main image. On mobile, main image area is swipeable (CSS scroll-snap or simple prev/next buttons).
3. **Product info** — name (h1), current price in XAF (updates on variant change), `compare_at_price` if present and higher than price (shown strikethrough with a "Sale" badge), category name (links to category PLP).
4. **Variant selector** — if product has variants with distinct `size_label`, show a size selector. If distinct `scent_label`, show a scent selector. Selectors use button groups (not dropdowns). Selecting a variant updates: displayed price, stock indicator, add-to-cart button state — all reactive, no page reload.
5. **Stock indicator** — based on selected variant's `stock_quantity`: `> 5` → "In Stock", `1–5` → "Low Stock (X left)", `0` → "Out of Stock".
6. **Quantity selector** — +/− buttons, minimum 1, maximum = available stock. Disabled when out of stock.
7. **Add to cart button** — calls `cartStore.addItem()` with selected variant and quantity. Shows loading spinner during add. On success: `uiStore.addToast('[Product Name] added to cart', 'success')`. Button text becomes "Out of Stock" and is disabled when `stock_quantity = 0`.
8. **Tabbed content** — three tabs (shadcn `Tabs`): "Description", "Ingredients", "How to Use". Content from `product.description`, `product.ingredients`, `product.usage_instructions`.
9. **Reviews section** — below the tabs. Shows: average star rating (out of 5), total review count, list of approved reviews (newest first, 5 per page with "Load more"). Each review: reviewer first name + last initial (e.g. "Stephanie M."), star rating, date, text. "No reviews yet" empty state. Authenticated shoppers with a completed order for this product see a "Write a Review" button (stub for Phase 4 — button visible but links to account with a `?review=productId` param).
10. **Related products** — a horizontal scroll row of up to 4 products in the same category (excluding current), each as `ProductCard`.
11. **Breadcrumb** — `Home > [Category Name] > [Product Name]`.
12. **JSON-LD structured data** — inject a `<script type="application/ld+json">` Product schema in `useHead()`: name, description, image, offers (price, currency: XAF, availability).
13. **SEO** — `useHead()` with `<title>[Product Name] — Thia</title>`, meta description from first 160 chars of product description, `og:image` from primary image URL.

- `components/product/StockIndicator.vue` — stock status display
- `components/product/QuantitySelector.vue` — +/− quantity input
- `components/product/ProductTabs.vue` — tabbed description/ingredients/usage

- `stores/ui.ts` — `addToast()`

## Implementation Tasks

- [ ] **Task 1: Create `StarRating.vue`** (AC: #9)
  - [ ] Props: `rating: number` (0–5), `interactive?: boolean`, `size?: 'sm'|'md'|'lg'`
  - [ ] Renders 5 star icons (Lucide `Star`). Filled stars for `Math.floor(rating)`, half-star for `.5` remainder (or just round), empty for rest
  - [ ] If `interactive`, emits `update:rating` on click (for review form in Phase 4)

- [ ] **Task 2: Create `StockIndicator.vue`** (AC: #5)
  - [ ] Props: `stock: number`
  - [ ] Renders: green "In Stock" if `> 5`, amber "Low Stock (X left)" if `1–5`, red "Out of Stock" if `0`

- [ ] **Task 3: Create `QuantitySelector.vue`** (AC: #6)
  - [ ] Props: `modelValue: number`, `max: number`, `disabled?: boolean`
  - [ ] Emits `update:modelValue`
  - [ ] "−" button (disabled if value = 1 or disabled = true), number display, "+" button (disabled if value = max or disabled = true)

- [ ] **Task 4: Create `VariantSelector.vue`** (AC: #4)
  - [ ] Props: `variants: ProductVariant[]`, `modelValue: string | null` (selected variant id)
  - [ ] Emits `update:modelValue`
  - [ ] Derives unique `size_label` values and unique `scent_label` values
  - [ ] Renders a button group for sizes (if more than one unique size) and a button group for scents (if more than one unique scent)
  - [ ] Selected button: filled/outlined style using brand colors
  - [ ] Logic: when size changes, auto-select first scent available for that size; `selectedVariant` computed from current size+scent selection

- [ ] **Task 5: Create `ProductImageGallery.vue`** (AC: #2)
  - [ ] Props: `images: Array<{ url: string, isPrimary: boolean }>`
  - [ ] State: `activeIndex` (starts at index of primary image)
  - [ ] Main image: `NuxtImg` with `loading="eager"` and `fetchpriority="high"`, aspect-ratio 1:1 or 4:5, object-cover
  - [ ] Thumbnails: horizontal row of `NuxtImg` thumbnails (64×64). Clicking sets `activeIndex`
  - [ ] Mobile swipe: use CSS `scroll-snap-type` on a horizontal scroll container, or show prev/next arrows

- [ ] **Task 6: Create `ProductTabs.vue`** (AC: #8)
  - [ ] Props: `description: string`, `ingredients: string`, `usage: string`
  - [ ] Uses shadcn `Tabs`, `TabsList`, `TabsTrigger`, `TabsContent`
  - [ ] Three tabs: "Description", "Ingredients", "How to Use"
  - [ ] Renders content as `<p>` with `whitespace-pre-line` for line breaks

- [ ] **Task 7: Create `ReviewList.vue`** (AC: #9)
  - [ ] Props: `productId: string`
  - [ ] Fetch approved reviews: `useAsyncData(\`reviews-\${productId}\`, () => supabase.from('reviews').select('id,rating,text,created_at,profiles(full_name)').eq('product_id', productId).eq('status', 'approved').order('created_at', { ascending: false }).limit(5))`
  - [ ] Compute average rating and count from reviews
  - [ ] Show: `StarRating` (average), count text "Based on X reviews"
  - [ ] List reviews: "Stephanie M.", `StarRating`, date (`toLocaleDateString`), text
  - [ ] "Load more" button: fetch next 5 (offset-based)
  - [ ] Empty state: "No reviews yet. Be the first to review this product!"

- [ ] **Task 8: Build `pages/products/[slug].vue`** (AC: #1–#13)
  - [ ] `definePageMeta({ layout: 'default' })`
  - [ ] Fetch product: `useAsyncData(\`product-\${slug}\`, () => supabase.from('products').select(\`*, categories(id,name,slug), product_variants(*), product_images(*)\`).eq('slug', slug).eq('is_published', true).single().then(r => r.data))`
  - [ ] If no product: `createError({ statusCode: 404, message: 'Product not found' })`
  - [ ] State: `selectedVariantId` (ref, initialized to first variant id), `quantity` (ref, 1)
  - [ ] `selectedVariant` computed from `selectedVariantId`
  - [ ] `addToCart()` handler: validate variant selected, call `cartStore.addItem({ variantId, quantity, product, variant })`, show toast
  - [ ] Layout: two-column on desktop (gallery left, info right), stacked on mobile
  - [ ] Render: `Breadcrumb`, `ProductImageGallery`, product name (`<h1>`), price + compare_at_price + sale badge, `VariantSelector`, `StockIndicator`, `QuantitySelector`, Add to Cart button, `ProductTabs`, `ReviewList`, related products `ProductGrid`
  - [ ] Fetch related: `useAsyncData(\`related-\${slug}\`, () => supabase.from('products').select('id,name,slug,categories(name),product_variants(price),product_images(url,is_primary)').eq('category_id', product.categoryId).eq('is_published', true).neq('id', product.id).limit(4))`
  - [ ] JSON-LD: `useHead({ script: [{ type: 'application/ld+json', innerHTML: JSON.stringify({ '@context': 'https://schema.org', '@type': 'Product', name, description, image, offers: { '@type': 'Offer', price: selectedVariant.price, priceCurrency: 'XAF', availability: stock > 0 ? 'InStock' : 'OutOfStock' } }) }] })`
  - [ ] SEO: `useHead({ title: \`\${product.name} — Thia\`, meta: [...] })`
