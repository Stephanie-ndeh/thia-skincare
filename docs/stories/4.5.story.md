## Description
Connect the existing `DiscountCodeInput.vue` component to the live `POST /discount-codes/validate` backend route. Users can apply a code in the cart, see a success or error message, and remove the code. The checkout order summary also displays the applied discount and allows removal.

## Technical Notes

**`components/cart/DiscountCodeInput.vue`**

Current state: component exists but may not be wired to the backend. Audit existing implementation first.

Expected internal state:
```ts
const code = ref('')
const isLoading = ref(false)
const errorMsg = ref('')
const successMsg = ref('')
```

Apply handler:
```ts
async function applyCode() {
  isLoading.value = true
  errorMsg.value = ''
  successMsg.value = ''
  try {
    await cartStore.applyDiscount(code.value)
    successMsg.value = `${code.value} applied — ${formatXAF(cartStore.discountAmount)} off`
  } catch (err) {
    errorMsg.value = err instanceof Error ? err.message : 'Invalid code'
  } finally {
    isLoading.value = false
  }
}
```

Note: `cartStore.applyDiscount()` already calls `POST /discount-codes/validate` internally (implemented in Story 3.2). The component just needs to call it and handle the response/error display.

**`components/checkout/CheckoutOrderSummary.vue`**

Add to the totals section:
```html
<div v-if="cartStore.discountCode" class="flex justify-between text-sm text-green-700">
  <span>{{ cartStore.discountCode }} <button @click="cartStore.removeDiscount()">Remove</button></span>
  <span>-{{ formatXAF(cartStore.discountAmount) }}</span>
</div>
```
