# Story 5.1 — Admin Dashboard & Overview

## Status
review

## Description
Implements the main admin dashboard page at `/admin` with high-level business metrics, a recent orders table, and a low-stock alert panel. The admin layout and sidebar already exist; this story wires up the dashboard content page and the backend `/admin/metrics` endpoint.

## Acceptance Criteria
- [x] `/admin` renders with `layout: 'admin'`, `ssr: false`, and `middleware: 'admin'`
- [x] AdminSidebar contains nav links: Dashboard, Products, Orders, Reviews, Client Photos, Discount Codes, Settings with correct hrefs
- [x] `AdminMetricsRow` displays 4 cards: Total Orders, Total Revenue (formatted XAF), Total Products, Total Customers
- [x] Each metric card shows a "this month" delta value when available from the API
- [x] `AdminRecentOrders` displays the last 10 orders in a table (ref, customer, date, total, status, actions)
- [x] Each row in the recent orders table has a View button linking to `/admin/orders/[id]`
- [x] Order status displayed as a colored badge
- [x] `AdminLowStockAlert` lists product variants with `stock_quantity < 5`, showing product name, variant label, and stock count
- [x] Each low-stock row links to `/admin/products/[id]`
- [x] `GET /admin/metrics` backend route is registered in `app.ts` and protected by `requireAdmin`
- [x] Metrics endpoint returns `{ total_orders, total_revenue, total_products, total_customers, orders_this_month, revenue_this_month }`
- [x] Page shows a loading state while metrics are being fetched
- [x] Page shows an error state if the metrics request fails

## Technical Notes
- File: `apps/frontend/pages/admin/index.vue`
- `definePageMeta({ layout: 'admin', ssr: false, middleware: 'admin' })`
- New components:
  - `components/admin/AdminMetricsRow.vue`
  - `components/admin/AdminRecentOrders.vue`
  - `components/admin/AdminLowStockAlert.vue`
- Backend route: `GET /admin/metrics` — `requireAdmin` preHandler
- Revenue formatting must use `formatXAF()` from `@thia/shared`
- Metrics response shape:
  ```ts
  {
    total_orders: number
    total_revenue: number
    total_products: number
    total_customers: number
    orders_this_month: number
    revenue_this_month: number
  }
  ```
- Total Customers = count from `profiles` where `role = 'customer'`
- Low-stock threshold is `stock_quantity < 5` on any `product_variants` row
- Register the metrics route in `apps/backend/src/app.ts`

## Dependencies
- Admin layout and `AdminSidebar` component must exist (already implemented)
- `admin` middleware must be in place (already implemented)
- `@thia/shared` `formatXAF` utility must be available
