# Story 2.5: Search Functionality

**Status:** ready-for-dev
**Phase:** 2 — Core Shop
**PRD Reference:** FR-2.8, FR-2.9, FR-2.10

## Story

As a guest visitor,
I want to search for products by name or keyword directly from the header,
so that I can find specific products quickly without browsing categories.

## Acceptance Criteria

1. **Search bar in header** — a search input or icon in `AppHeader`. On desktop: an expandable input that appears on icon click (or always-visible input). On mobile: magnifying glass icon that opens a full-width search bar (slides down or opens a modal/sheet).
2. **Debounced search** — typing triggers a search query after 300ms debounce (minimum 2 characters). Fewer than 2 characters: no query, clear results.
3. **Search results page** — URL: `/search?q=[term]`. Renders SSR for direct URL access. Shows matching products in a responsive grid with result count "X products found for '[term]'".
4. **Search logic** — uses Supabase PostgreSQL full-text search on the `search_vector` column (already exists on `products` table, generated from name + description). Query: `supabase.from('products').select('...').textSearch('search_vector', term, { type: 'websearch' })`.
5. **Instant preview dropdown** — while typing in the header search bar, show a floating dropdown with up to 5 matching product results (image + name + price). Clicking a result navigates to the PDP. Clicking "See all results for '[term]'" or pressing Enter navigates to `/search?q=[term]`.
6. **No results state** — if no products match: "No products found for '[term]'" + "Browse all products" CTA linking to `/categories`.
7. **Search page also allows sort/filter** — the search results page reuses `ProductSortSelect` and `ProductFilters` (from US-011) to allow refining results.
8. **Performance** — search results return within 500ms. The Supabase GIN index on `search_vector` should ensure this. No client-side JS full-text search.
9. **Clear search** — a "×" button inside the search input clears the query and closes/hides the preview dropdown.
10. **Keyboard** — pressing Enter in the search bar navigates to `/search?q=[term]`. Pressing Escape closes the preview dropdown. Arrow keys move focus through dropdown items.

  - [ ] Accept `query: Ref<string>`

    - `loading = true`
