# Story 3.1–3.4: Cart Functionality

**Status:** ready-for-dev
**Phase:** 2 — Core Shop (accelerated from PRD Phase 3)
**PRD Reference:** FR-3.1–FR-3.5

## Story

As a guest or authenticated shopper,
I want a cart drawer and cart page where I can review, adjust, and prepare my items for checkout,
so that I can purchase the right products in the right quantities.

## Acceptance Criteria

1. **Cart drawer** — a slide-in Sheet from the right, triggered by clicking the cart icon in the header. Shows all cart items, subtotal, and a "Proceed to Checkout" button. Does not navigate away — overlay on current page.
2. **Cart page** (`/cart`) — full-page cart view at `/cart` (CSR, no SSR). Same items and totals as drawer. "Continue Shopping" link (→ last visited category or `/categories`).
3. **Cart item display** — each item shows: product image (60×60 thumbnail), product name, variant label (e.g. "50ml / Rose"), unit price in XAF, quantity control (+/− buttons), line total (unit × qty), remove button (trash icon, no confirmation dialog).
4. **Real-time totals** — cart subtotal, discount amount (if applied), and order total update reactively as quantities change. All in XAF using `formatXAF`.
5. **Quantity controls** — "−" decreases by 1 (minimum 1 — removing requires the trash button). "+" increases by 1. No stock cap enforced in cart UI (Phase 3 will validate at checkout).
6. **Remove item** — clicking trash icon calls `cartStore.removeItem(itemId)`. Item disappears immediately with no confirmation.
7. **Empty cart state** — when cart is empty: illustration or icon, "Your cart is empty", CTA button "Browse Products" → `/categories`.
8. **Discount code input** — a collapsible "Have a promo code?" section. Input + "Apply" button. On apply: calls `useDiscountCode` composable which validates via Supabase (`discount_codes` table: check active, not expired, usage_limit not exceeded, minimum_order met). Displays: applied code with discount amount and "Remove" link, OR specific error message. Only one code per cart.
9. **Cart icon badge** — the cart icon in `AppHeader` shows a red count badge with total item count. Updates reactively from `cartStore.itemCount`. Shows nothing (no badge) when count = 0.
10. **Proceed to checkout** — button in drawer and cart page. Disabled when cart is empty. Routes to `/checkout` (stub page for now — Phase 3 will implement checkout). If user is not authenticated, redirect to `/auth/login?redirect=/checkout`.
11. **Cart persistence** — already implemented in `cart.ts` store (localStorage for guests). This story just consumes the store — do not modify persistence logic.
12. **Opening cart drawer** — clicking cart icon calls `uiStore` action to open drawer, OR use a local `isOpen` ref managed in `AppHeader`. Header integration must open drawer without navigating.
