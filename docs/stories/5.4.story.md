# Story 5.4 — Review Management

## Status
review

## Description
Implements the admin review moderation page where admins can view, filter, approve, reject, and bulk-action customer product reviews. Backend routes provide filtered review data and individual status updates.

## Acceptance Criteria
- [x] `/admin/reviews` displays a table: Product, Customer, Rating, Review text (truncated), Date, Status, Actions
- [x] Table supports filter by status: pending, approved, rejected
- [x] Pending reviews are visually highlighted (e.g. row background or badge)
- [x] Each row has an Approve button that sets `status = 'approved'`
- [x] Each row has a Reject button that sets `status = 'rejected'`
- [x] Approve/Reject actions call `PATCH /admin/reviews/:id` and update the row optimistically or refresh
- [x] Rows have checkboxes enabling multi-select
- [x] A bulk action toolbar appears when one or more rows are selected
- [x] Bulk toolbar has "Approve selected" and "Reject selected" buttons
- [x] Bulk actions call `PATCH /admin/reviews/bulk` with all selected IDs in one request
- [x] `GET /admin/reviews` accepts query params: `status`, `page`, `limit` (requireAdmin)
- [x] Response includes product name and customer name joined from related tables
- [x] `PATCH /admin/reviews/:id` accepts `{ status: 'approved' | 'rejected' }` (requireAdmin)
- [x] All routes registered in `app.ts`

## Technical Notes
- File: `apps/frontend/pages/admin/reviews/index.vue`
- `definePageMeta({ layout: 'admin', ssr: false, middleware: 'admin' })`
- Review status type: `'pending' | 'approved' | 'rejected'`
- `GET /admin/reviews` joins `reviews` with `products` (for name) and `profiles` (for customer name)
- Default filter on page load: show `pending` reviews first (or all, with pending highlighted)
- Optimistic UI update: flip the status badge immediately on button click, revert on error
- Pagination recommended but not required for MVP — implement if review volume warrants it
