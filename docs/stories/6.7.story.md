# Story 6.7 — Deployment (Vercel + Render.com)

## Status
ready-for-dev

## Description
Deploy the frontend to Vercel and the backend to Render.com. Configure environment variables, Supabase auth redirect URLs, and CORS for production. Smoke-test the live site end to end.

## Acceptance Criteria
- [ ] `nuxt.config.ts` uses `runtimeConfig` for all environment values; no hardcoded `localhost` URLs anywhere in the frontend codebase
- [ ] Frontend deployed to Vercel with correct env vars (`SUPABASE_URL`, `SUPABASE_KEY`, `NUXT_PUBLIC_API_BASE_URL`, `NUXT_PUBLIC_SITE_URL`)
- [ ] Backend `apps/backend/src/config/env.ts` reads `PORT` from `process.env.PORT`
- [ ] `apps/backend/package.json` has `"start": "node dist/server.js"` in scripts
- [ ] Backend deployed to Render.com with build command `npm install && npm run build`, start command `npm start`, and all `.env` vars set
- [ ] Supabase Auth → URL Configuration includes the Vercel production URL in allowed redirect URLs
- [ ] Backend CORS allows the Vercel production URL
- [ ] Smoke test passes: homepage loads, categories/products display, register/login works, cart functions, admin panel accessible, all images load from Supabase Storage
- [ ] `.env` files are gitignored and not committed to the repository

## Technical Notes
- Vercel: set Root Directory to `apps/frontend` in project settings (monorepo setup)
- Render.com: set Root Directory to `apps/backend`; free tier Web Services spin down after inactivity — warn the client
- After getting the Render URL, update Vercel env `NUXT_PUBLIC_API_BASE_URL` and redeploy frontend
- Supabase redirect URLs: add both `https://[vercel-url]/**` and the custom domain (when available)
- CORS update in backend: add Vercel URL alongside existing `FRONTEND_URL` env var, or update `FRONTEND_URL` to the Vercel URL
- Custom domain: Vercel Dashboard → Domains; update DNS at registrar (A/CNAME records)
- NotchPay webhook URL must be updated from ngrok to `https://[render-url]/payments/webhook` in the NotchPay dashboard after backend deployment

## Dependencies
- All other Phase 6 stories (6.1–6.6) should be complete before deployment
- Story 6.4 (NotchPay Payment Fix) webhook URL must be updated post-deployment

- [ ] All acceptance criteria met
- [ ] Zero TypeScript errors
