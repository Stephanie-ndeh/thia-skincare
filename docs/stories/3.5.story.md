# Story 3.5 — Checkout Page (Frontend)

## Status
ready-for-dev

## Description
Build the multi-step checkout page where authenticated users enter delivery details, select a mobile money payment channel, review their order summary, and submit the order. Shipping cost is calculated live as the user types their city.

## Acceptance Criteria
- [ ] Page at `pages/checkout.vue` with `definePageMeta({ layout: 'checkout', ssr: false })`
- [ ] Unauthenticated users are redirected to `/auth/login?redirect=/checkout` by the `auth` middleware
- [ ] `DeliveryForm.vue` collects: `full_name`, `phone`, `city`, `address`, `region`
- [ ] Phone field validated with `isValidCameroonPhone()` from `@thia/shared` on blur; inline error shown if invalid
- [ ] Region field is a dropdown populated from `CAMEROON_REGIONS` constant from `@thia/shared`
- [ ] City field change triggers a debounced (500ms) call to `POST /shipping/calculate`; shipping rate updates reactively
- [ ] `PaymentMethodSelector.vue` displays MTN Mobile Money (`cm.mtn`) and Orange Money (`cm.orange`) as styled radio cards
- [ ] `CheckoutOrderSummary.vue` shows cart items, subtotal, shipping, discount (if any), and total — all via `formatXAF()`
- [ ] "Place Order" button disabled while any required field is empty or phone is invalid
- [ ] Place Order flow: validate form → `POST /orders` → `POST /payments/initialize` → redirect to `payment_url`
- [ ] Loading state shown on Place Order button during API calls
- [ ] Error state shown if either API call fails (message displayed above button)

## Technical Notes

**Components to create**:

`components/checkout/DeliveryForm.vue`
- Props: `modelValue: DeliveryData` (emit updates via `update:modelValue`)
- `DeliveryData` interface: `{ fullName: string; phone: string; city: string; address: string; region: string }`
- Phone validation: `isValidCameroonPhone(phone)` on blur — show red error text if false
- City input: `watch(city, debounce(() => emit('city-changed', city), 500))`
- Region: `<select>` with options from `CAMEROON_REGIONS`

`components/checkout/PaymentMethodSelector.vue`
- Props: `modelValue: 'cm.mtn' | 'cm.orange'`
- Two styled radio cards; selected card has highlighted border
- Emit `update:modelValue` on selection

`components/checkout/CheckoutOrderSummary.vue`
- Props: `{ items: CartItemWithProduct[], subtotal: number, shippingRate: number, discountAmount: number, discountCode: string | null, total: number }`
- All prices rendered with `formatXAF()`
- Shipping row shows "Free" when rate is 0

**Place Order flow** (in `pages/checkout.vue` or `composables/useCheckout.ts`):
```ts
const order = await $fetch(`${apiBase}/orders`, { method: 'POST', body: orderPayload })
const payment = await $fetch(`${apiBase}/payments/initialize`, {
  method: 'POST',
  body: { orderId: order.data.id, channel: selectedChannel, ... }
})
await navigateTo(payment.data.payment_url, { external: true })
```
