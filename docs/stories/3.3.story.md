# Story 3.3 — Order Creation (Backend)

## Status
ready-for-dev

## Description
Implement backend routes to create a new order from cart contents and retrieve order history. Order creation validates stock, computes all monetary values as integers, applies any discount, generates a human-readable reference, and persists both the order header and line items atomically.

## Acceptance Criteria
- [ ] `POST /orders` requires authentication (`fastify.authenticate`)
- [ ] `POST /orders` validates that every line item has sufficient stock
- [ ] All monetary values stored and returned as XAF integers (no decimals)
- [ ] Percentage discount uses `Math.floor(subtotal * value / 100)`
- [ ] Order reference generated in format `THIA-XXXXXX` (6 random uppercase alphanumeric characters)
- [ ] Order row and all `order_items` rows created in a single atomic operation
- [ ] `POST /orders` returns `{ data: Order }` with full order and items
- [ ] `GET /orders/:id` requires authentication; returns 404 if order belongs to another user
- [ ] `GET /orders` requires authentication; returns `PaginatedResponse<Order>` (default page size 10)
- [ ] All three routes registered in `src/app.ts`
- [ ] `CreateOrderRequest` added to `packages/shared/types/order.ts`

## Technical Notes

**New shared type** — add to `packages/shared/types/order.ts`:
```ts
export interface CreateOrderRequest {
  items: Array<{
    variantId: string
    quantity: number
    unitPrice: number
  }>
  discountCode?: string
  discountAmount?: number
  shippingZoneId?: string
  shippingAmount: number
  deliveryAddress: {
    fullName: string
    phone: string
    city: string
    address: string
    region: string
  }
}
```

**Route file**: `apps/backend/src/routes/orders/index.ts`

**Order creation logic**:
1. Authenticate request → get `userId`
2. For each item: query `product_variants` for `stock_quantity`; if any variant has insufficient stock → `AppError(400, 'OUT_OF_STOCK', '...')`
3. Compute `subtotal = sum(unitPrice * quantity)` — integers only
4. Apply discount: `type === 'percentage'` → `Math.floor(subtotal * value / 100)`; `type === 'fixed'` → `Math.min(value, subtotal)`
5. `total = subtotal - discountAmount + shippingAmount`
6. Generate reference: `'THIA-' + randomBytes(3).toString('hex').toUpperCase()`
7. Insert into `orders` table; insert all rows into `order_items` table
8. Return full order with items

**`GET /orders`** pagination: `?page=1&limit=10`, return `{ data: Order[], meta: { total, page, limit, totalPages } }`

**`GET /orders/:id`**: query by id AND `user_id = request.user.id`; throw `AppError(404)` if not found

**Registration**: `fastify.register(ordersRoutes)` in `src/app.ts`
