# Story 6.2 — UI Polish & Animations

## Status
review

## Description
The site feels premium and smooth through consistent micro-animations, page transitions, hover states, skeleton loaders, and a final currency string audit to replace all remaining "FCFA" occurrences with `formatXAF()`.

## Acceptance Criteria
- [x] Global page transition configured in `nuxt.config.ts` (`name: 'page'`, `mode: 'out-in'`)
- [x] CSS transition classes `.page-enter-active`, `.page-leave-active`, `.page-enter-from`, `.page-leave-to` added to `assets/css/main.css` with opacity + translateY
- [x] Product cards animate to `scale(1.02)` with shadow on hover
- [x] Buttons darken on hover and scale to `0.98` on active/click
- [x] Cart drawer slides in from the right with `ease-out`
- [x] Toast notifications slide in from bottom-right
- [x] Product images fade in on load via `@load` event handler
- [x] Skeleton loaders have a shimmer animation
- [x] `AnnouncementStrip` marquee is smooth; pauses on hover via `animation-play-state: paused`
- [x] All product `<img>` elements have `loading="lazy"` and an `@error` handler showing a placeholder
- [x] Zero remaining `"FCFA"` string literals in any `.vue` or `.ts` file — all replaced with `formatXAF()` from `@thia/shared`

## Technical Notes
- Page transition CSS must live in `assets/css/main.css` (globally available) not scoped inside a component
- Use Tailwind `transition`, `duration-200`, `ease-out` utilities where possible; write raw CSS only when Tailwind utilities aren't sufficient
- `formatXAF()` is exported from `packages/shared` — import via `@thia/shared`
- Audit command: `grep -r "FCFA" apps/frontend/` — result must be empty after fix
- Skeleton shimmer: use a `@keyframes shimmer` with background-position animation

## Dependencies
None — this story can be started independently.
