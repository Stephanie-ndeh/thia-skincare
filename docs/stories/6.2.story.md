# Story 6.2 — UI Polish & Animations

## Status
ready-for-dev

## Description
The site feels premium and smooth through consistent micro-animations, page transitions, hover states, skeleton loaders, and a final currency string audit to replace all remaining "FCFA" occurrences with `formatXAF()`.

## Acceptance Criteria
- [ ] Global page transition configured in `nuxt.config.ts` (`name: 'page'`, `mode: 'out-in'`)
- [ ] CSS transition classes `.page-enter-active`, `.page-leave-active`, `.page-enter-from`, `.page-leave-to` added to `assets/css/main.css` with opacity + translateY
- [ ] Product cards animate to `scale(1.02)` with shadow on hover
- [ ] Buttons darken on hover and scale to `0.98` on active/click
- [ ] Cart drawer slides in from the right with `ease-out`
- [ ] Toast notifications slide in from bottom-right
- [ ] Product images fade in on load via `@load` event handler
- [ ] Skeleton loaders have a shimmer animation
- [ ] `AnnouncementStrip` marquee is smooth; pauses on hover via `animation-play-state: paused`
- [ ] All product `<img>` elements have `loading="lazy"` and an `@error` handler showing a placeholder
- [ ] Zero remaining `"FCFA"` string literals in any `.vue` or `.ts` file — all replaced with `formatXAF()` from `@thia/shared`

## Technical Notes
- Page transition CSS must live in `assets/css/main.css` (globally available) not scoped inside a component
- Use Tailwind `transition`, `duration-200`, `ease-out` utilities where possible; write raw CSS only when Tailwind utilities aren't sufficient
- `formatXAF()` is exported from `packages/shared` — import via `@thia/shared`
- Audit command: `grep -r "FCFA" apps/frontend/` — result must be empty after fix
- Skeleton shimmer: use a `@keyframes shimmer` with background-position animation

## Dependencies
None — this story can be started independently.

## Definition of Done
- [ ] All acceptance criteria met
- [ ] Zero TypeScript errors
- [ ] No `any` types
- [ ] Reviewed by QA
