# Story 5.2 — Product Management (CRUD)

## Status
ready-for-dev

## Description
Implements the full product management section of the admin panel: a searchable/filterable product listing, a shared `ProductForm` component used for both creating and editing products, image uploads to Supabase Storage, and all required backend routes.

## Acceptance Criteria
- [ ] `/admin/products` lists all products in a table (Image, Name, Category, Variants count, Stock, Status, Actions)
- [ ] Product list supports search by name (client-side or query param)
- [ ] Product list supports filter by category
- [ ] Each row has an inline toggle for `is_published` that PATCHes immediately
- [ ] Each row has an inline toggle for `is_featured` that PATCHes immediately
- [ ] Edit button on each row navigates to `/admin/products/[id]`
- [ ] Delete button shows a confirmation dialog before soft-deleting (`is_published = false`)
- [ ] "Add Product" button navigates to `/admin/products/new`
- [ ] `/admin/products/new` and `/admin/products/[id]` both use the shared `ProductForm` component
- [ ] `ProductForm` fields: Name (required), Slug (auto-generated, editable), Category (dropdown), Description, Ingredients, Usage Instructions, Is Published (toggle), Is Featured (toggle)
- [ ] Slug is auto-generated from name but remains manually editable
- [ ] Variants section allows adding/removing rows; each row has Size label, Scent label, Price (XAF), Stock quantity
- [ ] At least 1 variant is required — form cannot be submitted without one
- [ ] Images section allows uploading to Supabase Storage bucket `product-images`
- [ ] Uploaded images display as thumbnails
- [ ] Admin can set a primary image
- [ ] Admin can delete an uploaded image
- [ ] `GET /admin/products` returns all products with variants and images (requireAdmin)
- [ ] `POST /admin/products` creates a product with its variants and images (requireAdmin)
- [ ] `PUT /admin/products/:id` updates product fields (requireAdmin)
- [ ] `DELETE /admin/products/:id` soft-deletes by setting `is_published = false` (requireAdmin)
- [ ] `POST /admin/products/:id/images` handles image upload (requireAdmin)
- [ ] `DELETE /admin/products/:id/images/:imageId` removes an image (requireAdmin)
- [ ] All routes registered in `app.ts`

## Technical Notes
- Files:
  - `apps/frontend/pages/admin/products/index.vue`
  - `apps/frontend/pages/admin/products/new.vue`
  - `apps/frontend/pages/admin/products/[id].vue`
  - `apps/frontend/components/admin/ProductForm.vue`
- All pages: `definePageMeta({ layout: 'admin', ssr: false, middleware: 'admin' })`
- Supabase Storage bucket: `product-images`
- Use `ProductWithVariants` type from `@thia/shared` for typing product data
- Price inputs must store values in XAF (integer); display with `formatXAF()`
- Slug generation: lowercase, replace spaces with `-`, strip non-alphanumeric except hyphens
- Backend soft-delete sets `is_published = false`; records are never hard-deleted via this route
- Image upload flow: upload file to storage → get public URL → save URL to `product_images` table with `is_primary` flag

## Dependencies
- Story 5.1 (Admin Dashboard) — admin layout, sidebar, and middleware must exist
