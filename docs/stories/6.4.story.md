# Story 6.4 — NotchPay Payment Fix

## Status
ready-for-dev

## Description
Complete the end-to-end payment flow using NotchPay (MTN Mobile Money + Orange Money). This includes wiring up the correct API request body, callback/cancel URLs, ngrok for local webhook testing, and verified-purchase enforcement on the reviews endpoint.

## Acceptance Criteria
- [ ] `payment.service.ts` sends correct body to `POST https://api.notchpay.co/payments` (email, phone, amount, currency: 'XAF', reference, callback, description)
- [ ] `callbackUrl` resolves to `${env.FRONTEND_URL}/order-confirmation`
- [ ] `cancelUrl` resolves to `${env.FRONTEND_URL}/checkout`
- [ ] ngrok configured locally; `NGROK_URL` in backend `.env` points to current ngrok HTTPS tunnel
- [ ] NotchPay dashboard webhook URL set to `https://[ngrok-url]/payments/webhook` for `payment.complete` event
- [ ] `NOTCHPAY_PUBLIC_KEY` and `NOTCHPAY_PRIVATE_KEY` in `.env` are single-line (no line breaks)
- [ ] Full payment flow works end to end: add product → checkout → place order → NotchPay page → test payment → `/order-confirmation` → order status `confirmed`
- [ ] `POST /reviews` requires `order_id` in request body; validates order belongs to authenticated user; validates order status is `'delivered'`; returns 403 if no qualifying order found

## Technical Notes
- NotchPay API request headers: `Authorization: YOUR_PUBLIC_KEY` (not `Bearer`), `Content-Type: application/json`
- `reference` field should be the order's `order_number`
- ngrok is for local dev only — production will use the deployed Render.com URL for webhook
- Restart backend after updating `.env`
- Verified-purchase check on reviews: query `orders` table where `id = order_id AND user_id = request.user.id AND status = 'delivered'`
- Do not break existing payment webhook handler — only update the outbound request shape

## Dependencies
None — this story can be started independently, though Story 6.7 (Deployment) supersedes the ngrok step in production.

- [ ] All acceptance criteria met
- [ ] Zero TypeScript errors
