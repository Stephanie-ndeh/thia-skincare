# Story 2.1: Homepage Sections

**Status:** ready-for-dev
**Phase:** 2 — Core Shop
**PRD Reference:** FR-2.1, FR-2.7, FR-2.11

## Story

As a guest visitor,
I want to land on a compelling, brand-forward homepage that showcases Thia's products and builds trust,
so that I understand what Thia offers and am motivated to browse or shop.

## Acceptance Criteria

1. **Hero section** — full-width banner with background image, headline, subheadline, and a CTA button. Image URL and CTA link are read from `site_settings` table (key: `homepage_hero`). Renders server-side (SSR).
2. **Featured categories grid** — displays all categories fetched from Supabase `categories` table, ordered by `display_order`. Each card shows category image, name, and links to `/categories/[slug]`. Responsive: 2 cols mobile, 3 cols tablet, 4-5 cols desktop.
3. **Best sellers / featured products section** — displays up to 8 products where `is_featured = true`, fetched from Supabase. Each shown as a `ProductCard` component (image, name, starting price, category badge, link to PDP). Responsive grid: 2 cols mobile, 3 tablet, 4 desktop.
4. **Testimonials carousel section** — displays testimonials where `is_featured = true` from the `testimonials` table, ordered by `display_order`. Wraps `TestimonialCarousel` component (see component list below). Shows 1 on mobile, 2 on tablet, 3 on desktop. Auto-rotates every 5 seconds with manual prev/next controls.
5. **Newsletter signup section** — static section with email input and submit button. On submit, show inline success message "You're on the list!". No backend needed — store email in a Supabase `newsletter_signups` table insert via `useSupabaseClient()`. If Supabase insert fails, fail silently and show success anyway (marketing only, not transactional).
6. **SEO** — `useHead()` sets `<title>Thia — Natural Skincare from Cameroon</title>` and meta description. All sections render server-side.
7. **Fallback states** — if no featured products or no testimonials exist, sections render gracefully with no visible empty boxes (hide the section or show a static placeholder message).
8. **Performance** — hero image uses `NuxtImg` with `loading="eager"` and `fetchpriority="high"`. All other images use `NuxtImg` with `loading="lazy"`.
