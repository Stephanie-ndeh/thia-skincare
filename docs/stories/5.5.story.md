# Story 5.5 — Client Photos Management

## Status
ready-for-dev

## Description
Implements the admin testimonials/client photos management page. Admins can view all testimonials in a grid, upload new photos to Supabase Storage, create or edit testimonial records, toggle featured status, reorder entries, and delete testimonials.

## Acceptance Criteria
- [ ] `/admin/photos` displays all testimonials in a responsive grid
- [ ] Each grid card shows the photo, customer name, review text, featured badge (if featured), and display order
- [ ] "Add Testimonial" form is accessible (modal or inline panel) with fields: customer_name, text, photo file upload, is_featured, display_order
- [ ] Photo upload stores the file in Supabase Storage bucket `testimonials` and saves the public URL as `photo_url`
- [ ] Toggling `is_featured` on a card calls `PUT /admin/testimonials/:id` and updates the card immediately
- [ ] Display order can be changed via a number input per card (or drag-to-reorder)
- [ ] Changing display order calls `PUT /admin/testimonials/:id` with the new `display_order`
- [ ] Delete button on each card shows a confirmation before calling `DELETE /admin/testimonials/:id`
- [ ] Editing an existing testimonial opens the same form pre-populated
- [ ] `GET /admin/testimonials` returns all testimonials ordered by `display_order` (requireAdmin)
- [ ] `POST /admin/testimonials` creates a new testimonial record (requireAdmin)
- [ ] `PUT /admin/testimonials/:id` updates any testimonial fields (requireAdmin)
- [ ] `DELETE /admin/testimonials/:id` removes the testimonial record (requireAdmin)
- [ ] All routes registered in `app.ts`

## Technical Notes
- File: `apps/frontend/pages/admin/photos/index.vue`
- `definePageMeta({ layout: 'admin', ssr: false, middleware: 'admin' })`
- Supabase Storage bucket: `testimonials`
- Testimonial record shape:
  ```ts
  {
    id: string
    customer_name: string
    text: string
    photo_url: string
    is_featured: boolean
    display_order: number
    created_at: string
  }
  ```
- Upload flow: upload file to `testimonials` bucket → get public URL → include `photo_url` in POST body
- If drag-to-reorder is implemented, use HTML5 drag-and-drop or a lightweight library; each drop triggers a PUT for the affected record(s)
- Number input for `display_order` is acceptable as the simpler fallback
