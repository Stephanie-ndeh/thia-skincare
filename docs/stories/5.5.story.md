# Story 5.5 — Client Photos Management

## Status
review

## Description
Implements the admin testimonials/client photos management page. Admins can view all testimonials in a grid, upload new photos to Supabase Storage, create or edit testimonial records, toggle featured status, reorder entries, and delete testimonials.

## Acceptance Criteria
- [x] `/admin/photos` displays all testimonials in a responsive grid
- [x] Each grid card shows the photo, customer name, review text, featured badge (if featured), and display order
- [x] "Add Testimonial" form is accessible (modal or inline panel) with fields: customer_name, text, photo file upload, is_featured, display_order
- [x] Photo upload stores the file in Supabase Storage bucket `testimonials` and saves the public URL as `photo_url`
- [x] Toggling `is_featured` on a card calls `PUT /admin/testimonials/:id` and updates the card immediately
- [x] Display order can be changed via up/down arrow buttons per card
- [x] Changing display order calls `PUT /admin/testimonials/:id` with the new `display_order`
- [x] Delete button on each card shows a confirmation before calling `DELETE /admin/testimonials/:id`
- [x] Editing an existing testimonial opens the same form pre-populated
- [x] `GET /admin/testimonials` returns all testimonials ordered by `display_order` (requireAdmin)
- [x] `POST /admin/testimonials` creates a new testimonial record (requireAdmin)
- [x] `PUT /admin/testimonials/:id` updates any testimonial fields (requireAdmin)
- [x] `DELETE /admin/testimonials/:id` removes the testimonial record and storage file (requireAdmin)
- [x] All routes registered in `app.ts`

## Technical Notes
- File: `apps/frontend/pages/admin/photos/index.vue`
- `definePageMeta({ layout: 'admin', ssr: false, middleware: 'admin' })`
- Supabase Storage bucket: `testimonials`
- Reorder uses up/down arrows (swap display_order with adjacent card, PUT both)
- Upload: multipart POST with fields + optional photo file (uses request.parts())
- Photo update: separate POST /admin/testimonials/:id/photo (replaces old storage file)
