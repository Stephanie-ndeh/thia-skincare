# Story 1.6: Pinia Stores — Auth, Cart & UI

Status: ready-for-dev

## Story

As a developer,
I want the three core Pinia stores (auth, cart, ui) implemented with their state, getters, and actions,
so that the frontend has centralized state management ready for feature development.

## Acceptance Criteria

1. Auth store manages: user session, profile data, role, login/logout/register methods via @nuxtjs/supabase
2. Cart store manages: cart items, add/remove/update quantity, discount code, subtotal/total calculation, localStorage persistence for guests, DB sync for authenticated users
3. UI store manages: mobile menu open/close, toast notification queue, global loading state
4. Cart store merges guest cart into DB cart on login per architecture doc Section 3.2
5. All monetary calculations use integer arithmetic (XAF, no decimals)
6. Stores are typed with interfaces from `@thia/shared`
7. Cart store persists to localStorage for guest users and survives browser close

## Tasks / Subtasks

- [ ] Task 1: Create auth store (AC: #1, #6)
  - [ ] Create `stores/auth.ts`
  - [ ] State: `user` (Supabase User | null), `profile` (Profile | null), `loading` (boolean)
  - [ ] Getters: `isAuthenticated`, `isAdmin`, `fullName`
  - [ ] Actions:
    - `fetchProfile()` — load profile from Supabase for current user
    - `login(email, password)` — call `supabase.auth.signInWithPassword`, fetch profile, trigger cart merge
    - `register(email, password, metadata)` — call `supabase.auth.signUp` with `full_name` and `phone` in metadata
    - `logout()` — call `supabase.auth.signOut`, clear profile, clear cart store DB state
    - `resetPassword(email)` — call `supabase.auth.resetPasswordForEmail`
    - `updatePassword(newPassword)` — call `supabase.auth.updateUser`
  - [ ] Initialize: watch `useSupabaseUser()` to auto-fetch profile on session change
- [ ] Task 2: Create cart store (AC: #2, #4, #5, #7)
  - [ ] Create `stores/cart.ts`
  - [ ] State: `items` (CartItemWithProduct[]), `discountCode` (string | null), `discountAmount` (number), `isLoading` (boolean)
  - [ ] Getters:
    - `itemCount` — total quantity across all items
    - `subtotal` — sum of (unit_price × quantity) as integer
    - `total` — subtotal - discountAmount (never negative, floor to 0)
    - `isEmpty` — items.length === 0
  - [ ] Actions:
    - `addItem(variantId, quantity, productData)` — add or increment quantity in cart
    - `updateQuantity(itemId, quantity)` — update item quantity (remove if 0)
    - `removeItem(itemId)` — remove item from cart
    - `clearCart()` — empty all items and discount
    - `applyDiscount(code)` — validate via API, store discount amount
    - `removeDiscount()` — clear discount code and amount
    - `syncToServer()` — push localStorage cart to DB for authenticated user
    - `loadFromServer()` — load cart from DB for authenticated user
    - `mergeGuestCart()` — merge localStorage items into DB cart (higher quantity wins on conflict)
  - [ ] Persistence:
    - Guest: serialize items to localStorage on every change, load on init
    - Authenticated: read/write via backend API (localStorage cleared after merge)
  - [ ] All price math: integer arithmetic only, use `Math.floor()` for percentage discounts
- [ ] Task 3: Create UI store (AC: #3)
  - [ ] Create `stores/ui.ts`
  - [ ] State: `isMobileMenuOpen` (boolean), `toasts` (Toast[]), `isGlobalLoading` (boolean)
  - [ ] Toast type: `{ id: string, message: string, type: 'success' | 'error' | 'info', duration: number }`
  - [ ] Actions:
    - `toggleMobileMenu()` — toggle open/close
    - `closeMobileMenu()` — force close
    - `addToast(message, type, duration?)` — add toast with auto-generated ID, default 3s duration
    - `removeToast(id)` — remove specific toast
    - `setGlobalLoading(loading)` — set loading state
  - [ ] Auto-dismiss: toasts removed after their duration via `setTimeout`
- [ ] Task 4: Create cart localStorage utility (AC: #7)
  - [ ] Create helper functions in cart store or separate util:
    - `saveCartToStorage(items)` — serialize to `thia-cart` localStorage key
    - `loadCartFromStorage()` — deserialize from `thia-cart`, return empty array if missing/invalid
    - `clearCartStorage()` — remove `thia-cart` key
  - [ ] Handle JSON parse errors gracefully (return empty cart)
- [ ] Task 5: Wire auth-cart integration (AC: #4)
  - [ ] On successful login (auth store): call `cartStore.mergeGuestCart()` then `cartStore.loadFromServer()`
  - [ ] On logout (auth store): call `cartStore.clearCart()` (DB cart preserved server-side, localStorage resumes)
  - [ ] Merge logic: for each localStorage item, if same variant exists in DB cart, keep max(localStorage.qty, db.qty); if not in DB, add it

## Dev Notes

- @nuxtjs/supabase provides `useSupabaseClient()` and `useSupabaseUser()` composables — use these in the auth store
- Cart API calls (`syncToServer`, `loadFromServer`, `mergeGuestCart`) will call the backend API once it's implemented. For now, stub these methods with TODO comments and implement only localStorage functionality
- Toast IDs: use `crypto.randomUUID()` or simple counter
- Cart merge is triggered ONCE on login, not on every page load
- `CartItemWithProduct` type from `@thia/shared` includes product display info (name, image, variant label) needed for the cart UI — store this alongside variant_id and quantity
