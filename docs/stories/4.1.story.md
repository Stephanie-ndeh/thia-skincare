## Technical Notes

**`pages/account/index.vue`**
```ts
definePageMeta({ layout: 'default', ssr: false, middleware: 'auth' })
```
Composes `AccountSidebar` and `AccountOverview`.

**`components/account/AccountSidebar.vue`**
- Links: Overview (`/account`), Orders (`/account/orders`), Wishlist (`/account/wishlist`), Profile (`/account/profile`), Addresses (`/account/addresses`)
- Reads `authStore.fullName` and `supabaseUser.value?.email` for display
- Uses `useRoute()` to determine active link
- On mobile (`< lg`): renders as a horizontal scrollable tab bar

**`components/account/AccountOverview.vue`**
- Greets with first name extracted from `authStore.fullName`
- Fetches `GET /orders?limit=3` on mount using `$fetch` with auth token
- Derives total orders count and total spent by summing order totals
- Renders recent orders as a compact list (reference, date, status badge, total)
- Quick links grid pointing to `/account/orders`, `/account/wishlist`, `/account/profile`

**API call pattern:**
```ts
const session = await useSupabaseClient().auth.getSession()
const token = session.data.session?.access_token
const res = await $fetch<{ data: Order[] }>(`${apiBase}/orders?limit=3`, {
  headers: { Authorization: `Bearer ${token}` },
})
```

**Status badge colors** (reuse across 4.2):
- `pending` → yellow
- `confirmed` → blue
- `processing` → purple
- `shipped` → orange
- `delivered` → green
- `cancelled` → red
