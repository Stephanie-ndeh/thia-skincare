# Story 4.3 — Product Reviews & Ratings

## Status
done

## Description
Allow authenticated customers to submit product reviews (rating 1–5 + text). Reviews are created with status `pending` and must be approved by an admin before appearing publicly. The product detail page shows the write-review form for logged-in users and a login prompt for guests.

## Acceptance Criteria
- [x] `POST /reviews` backend route implemented, requires `authenticate`
- [x] Route validates body: `product_id` (uuid), `rating` (integer 1–5), `text` (min 20 chars)
- [x] Route prevents duplicate reviews — returns error if user has already reviewed the product
- [x] Created review has `status = 'pending'`
- [x] Route returns the created review in `{ data: Review }` envelope
- [x] `CreateReviewRequest` interface added to `packages/shared/types/review.ts`
- [x] Backend route registered in `app.ts`
- [x] `components/review/WriteReviewForm.vue` created
- [x] Star rating selector allows clicking to set 1–5
- [x] Text area enforces minimum 20 characters (shown as character count / hint)
- [x] Submit calls `POST /reviews` with auth token
- [x] On success: toast "Review submitted for approval" and form resets
- [x] On error: specific error message shown via toast
- [x] Submit button shows loading state
- [x] `pages/products/[slug].vue` updated to show `WriteReviewForm` below the reviews list
- [x] Form only shown when `authStore.isAuthenticated` is true
- [x] Unauthenticated users see "Login to write a review" link pointing to `/auth/login`
- [x] After successful submit the reviews list refreshes
