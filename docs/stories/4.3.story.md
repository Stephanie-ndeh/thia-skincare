# Story 4.3 — Product Reviews & Ratings

## Status
ready-for-dev

## Description
Allow authenticated customers to submit product reviews (rating 1–5 + text). Reviews are created with status `pending` and must be approved by an admin before appearing publicly. The product detail page shows the write-review form for logged-in users and a login prompt for guests.

## Acceptance Criteria
- [ ] `POST /reviews` backend route implemented, requires `authenticate`
- [ ] Route validates body: `product_id` (uuid), `rating` (integer 1–5), `text` (min 20 chars)
- [ ] Route prevents duplicate reviews — returns error if user has already reviewed the product
- [ ] Created review has `status = 'pending'`
- [ ] Route returns the created review in `{ data: Review }` envelope
- [ ] `CreateReviewRequest` interface added to `packages/shared/types/review.ts`
- [ ] Backend route registered in `app.ts`
- [ ] `components/review/WriteReviewForm.vue` created
- [ ] Star rating selector allows clicking to set 1–5
- [ ] Text area enforces minimum 20 characters (shown as character count / hint)
- [ ] Submit calls `POST /reviews` with auth token
- [ ] On success: toast "Review submitted for approval" and form resets
- [ ] On error: specific error message shown via toast
- [ ] Submit button shows loading state
- [ ] `pages/products/[slug].vue` updated to show `WriteReviewForm` below the reviews list
- [ ] Form only shown when `authStore.isAuthenticated` is true
- [ ] Unauthenticated users see "Login to write a review" link pointing to `/auth/login`
- [ ] After successful submit the reviews list refreshes
