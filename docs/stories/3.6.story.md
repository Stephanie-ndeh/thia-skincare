# Story 3.6 — Order Confirmation Page (Frontend)

## Status
ready-for-dev

## Description
Build the order confirmation page that NotchPay redirects to after payment. The page reads transaction details from query parameters, verifies payment status with the backend, and shows either a success state (with order summary) or a failure state (with retry and support options).

## Acceptance Criteria
- [ ] Page at `pages/order-confirmation.vue` with `definePageMeta({ layout: 'default', ssr: false })`
- [ ] On mount, reads `?reference=` and `?transaction=` query parameters
- [ ] If either param is missing, shows an error state immediately without calling the API
- [ ] Calls `POST /payments/verify` with the reference on mount
- [ ] Shows a loading state while the verification call is in flight
- [ ] **Success state**: animated checkmark, "Order Confirmed" heading, order reference (`THIA-XXXXXX`), list of ordered items with quantities and prices, order total, "Continue Shopping" button → `/categories`
- [ ] **Success state**: calls `cartStore.clearCart()` after confirmed payment
- [ ] **Failure state**: error icon, "Payment Failed" heading, descriptive message, "Try Again" button → `/checkout`, support contact block with MTN and Orange Money phone numbers
- [ ] All prices displayed with `formatXAF()`

## Technical Notes

**File**: `apps/frontend/pages/order-confirmation.vue`

**On-mount logic**:
```ts
const route = useRoute()
const reference = route.query.reference as string | undefined
const transaction = route.query.transaction as string | undefined

onMounted(async () => {
  if (!reference || !transaction) {
    status.value = 'error'
    return
  }
  try {
    const result = await $fetch(`${apiBase}/payments/verify`, {
      method: 'POST',
      body: { reference }
    })
    if (result.data.status === 'complete') {
      order.value = result.data.order
      cartStore.clearCart()
      status.value = 'success'
    } else {
      status.value = 'error'
    }
  } catch {
    status.value = 'error'
  }
})
```

**State machine**: `status: 'loading' | 'success' | 'error'`

**Support contact numbers** (use constants from `@thia/shared` if available, otherwise hardcode):
- MTN MoMo support
- Orange Money support

**Success state items list**: rendered from `order.items` — each row shows product name, variant, quantity, and line total.
