# Story 6.1 — SEO & Meta Tags

## Status
review

## Description
Every page has proper SEO meta tags for Google and social sharing. This includes per-page `useHead()` / `useSeoMeta()` calls, a global `app.head` configuration in `nuxt.config.ts`, a generated sitemap, and a `robots.txt` file.

## Acceptance Criteria
- [x] `pages/index.vue` has title `'Thia — Natural Skincare from Cameroon'`, description, og:image, og:type
- [x] `pages/categories/[slug].vue` has dynamic title `'[Category Name] — Thia Skincare'` and description from `category.description`
- [x] `pages/products/[slug].vue` has dynamic title `'[Product Name] — Thia Skincare'`, dynamic description, and complete JSON-LD Product schema (name, description, image, offers with XAF currency, aggregateRating)
- [x] `pages/cart.vue` has title `'Your Cart — Thia'` and `noindex: true`
- [x] `pages/checkout.vue` has title `'Checkout — Thia'` and `noindex: true`
- [x] `pages/auth/login.vue` has title `'Sign In — Thia'` and `noindex: true`
- [x] All `pages/account/*.vue` pages have title `'My Account — Thia'` and `noindex: true`
- [x] All `pages/admin/*.vue` pages have `noindex: true`
- [x] `nuxt.config.ts` `app.head` includes `theme-color` meta, canonical link, Open Graph defaults, and Twitter card defaults
- [x] `@nuxtjs/sitemap` installed and configured; sitemap includes `/`, `/categories`, all category slugs, all published product slugs; excludes `/cart`, `/checkout`, `/auth/*`, `/account/*`, `/admin/*`
- [x] `robots.txt` allows `/`, disallows `/admin/`, `/account/`, `/cart`, `/checkout`, `/auth/`; includes Sitemap directive

## Technical Notes
- Use `useSeoMeta()` for simple pages; use `useHead()` when you need JSON-LD script injection
- JSON-LD for products goes inside a `<script type="application/ld+json">` tag via `useHead({ script: [...] })`
- `@nuxtjs/sitemap` is installed as a Nuxt module in `nuxt.config.ts`; configure `sitemapName`, `autoI18n: false`, and routes callback that queries Supabase for live slugs
- Canonical URL should be constructed from `NUXT_PUBLIC_SITE_URL` runtime config
- Twitter card type: `summary_large_image`

## Dependencies
None — this story can be started independently.
