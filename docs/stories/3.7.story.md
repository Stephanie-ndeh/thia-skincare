## Technical Notes

**`composables/useCheckout.ts`**:
```ts
interface CheckoutState {
  isLoading: boolean
  error: string | null
  deliveryData: DeliveryData | null
  selectedChannel: 'cm.mtn' | 'cm.orange'
  shippingRate: number
  shippingZoneName: string
  isFreeShipping: boolean
  orderId: string | null
}

// DeliveryData matches DeliveryForm.vue props:
interface DeliveryData {
  fullName: string
  phone: string
  city: string
  address: string
  region: string
}

export function useCheckout() {
  const state = reactive<CheckoutState>({ ... })
  const config = useRuntimeConfig()
  const cartStore = useCartStore()
  const supabase = useSupabaseClient()

  async function calculateShipping(city: string): Promise<void>
  async function placeOrder(): Promise<void>
  async function verifyPayment(transactionRef: string): Promise<PaymentVerifyResponse>

  return { state, calculateShipping, placeOrder, verifyPayment }
}
```

**`placeOrder()` sequence**:
1. Set `state.isLoading = true`, clear `state.error`
2. Build `CreateOrderRequest` from `cartStore.items`, `state.deliveryData`, `state.shippingRate`, `cartStore.discountCode`, `cartStore.discountAmount`
3. `POST /orders` → get `orderId`
4. `POST /payments/initialize` → get `payment_url`
5. `navigateTo(payment_url, { external: true })`
6. On any error: set `state.error = err.message`, `state.isLoading = false`

**`stores/cart.ts` — `syncToServer()`**:
```ts
async function syncToServer() {
  if (!isAuthenticated.value) return
  const session = await useSupabaseClient().auth.getSession()
  const token = session.data.session?.access_token
  if (!token) return
  isLoading.value = true
  try {
    await $fetch(`${useRuntimeConfig().public.apiBaseUrl}/cart/sync`, {
      method: 'POST',
      headers: { Authorization: `Bearer ${token}` },
      body: { items: items.value },
    })
  } finally {
    isLoading.value = false
  }
}
```

**`stores/cart.ts` — `loadFromServer()`**: Mirror of sync but `GET /cart`, replaces `items.value` with server response.
