# Story 4.2 — Order History & Order Detail

## Status
ready-for-dev

## Description
Implement the order history list page (paginated, 10 per page) and the individual order detail page showing full order information including items, shipping address, payment method, and price breakdown.

## Acceptance Criteria
- [ ] `pages/account/orders/index.vue` exists with correct `definePageMeta`
- [ ] Order history fetches `GET /orders` paginated at 10 per page
- [ ] Each order row shows: reference, date, status badge, total
- [ ] Status badges are colour-coded (pending/confirmed/processing/shipped/delivered/cancelled)
- [ ] Pagination controls navigate between pages
- [ ] Empty state renders "No orders yet" with a CTA linking to the shop
- [ ] `pages/account/orders/[id].vue` exists with correct `definePageMeta`
- [ ] Order detail fetches `GET /orders/:id` using the route param
- [ ] Detail page shows order reference, date, and status
- [ ] Items list shows image, product name, variant, quantity, and unit price
- [ ] Shipping address section rendered
- [ ] Payment method section rendered
- [ ] Price breakdown shows subtotal, shipping, discount (if any), and total
- [ ] All prices formatted with `formatXAF()`
- [ ] Breadcrumb renders: Account > Orders > THIA-XXXXXX

## Technical Notes

**`pages/account/orders/index.vue`**
```ts
definePageMeta({ layout: 'default', ssr: false, middleware: 'auth' })
```
- Query param `?page=N` drives pagination
- Fetches `GET /orders?page=N&limit=10`
- API response shape: `{ data: Order[], meta: { total, page, limit, totalPages } }`

**`pages/account/orders/[id].vue`**
```ts
definePageMeta({ layout: 'default', ssr: false, middleware: 'auth' })
```
- Route param: `const { id } = useRoute().params`
- Fetches `GET /orders/:id`
- Displays `404` or error state if order not found or belongs to another user

**Status badge colour map:**
```ts
const statusColors: Record<string, string> = {
  pending:    'bg-yellow-100 text-yellow-800',
  confirmed:  'bg-blue-100 text-blue-800',
  processing: 'bg-purple-100 text-purple-800',
  shipped:    'bg-orange-100 text-orange-800',
  delivered:  'bg-green-100 text-green-800',
  cancelled:  'bg-red-100 text-red-800',
}
```

**Auth header pattern** (same as 4.1):
```ts
const session = await useSupabaseClient().auth.getSession()
const token = session.data.session?.access_token
```

**Types** — use existing `Order` and `OrderItem` from `@thia/shared`.
