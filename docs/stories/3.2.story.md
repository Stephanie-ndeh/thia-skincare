# Story 3.2 — Discount Code Validation (Backend)

## Status
ready-for-dev

## Description
Implement a backend route that validates a discount code against business rules and returns a typed response. Move the `DiscountValidateResponse` type to `@thia/shared` and remove the local definition from `stores/cart.ts`.

## Acceptance Criteria
- [ ] `POST /discount-codes/validate` accepts `{ code: string, subtotal?: number }`
- [ ] Code lookup is case-insensitive
- [ ] Returns `{ valid: false, message: '...' }` if code is not found or inactive
- [ ] Returns `{ valid: false, message: '...' }` if `expires_at` is set and has passed
- [ ] Returns `{ valid: false, message: '...' }` if `usage_limit` is set and `times_used >= usage_limit`
- [ ] Returns `{ valid: false, message: '...' }` if `subtotal` is provided and is below `min_order_amount`
- [ ] Returns full `DiscountValidateResponse` with `valid: true` on success
- [ ] Does NOT increment `times_used` — that happens only on payment completion (Story 3.4)
- [ ] Route registered in `src/app.ts`
- [ ] `DiscountCode`, `DiscountValidateRequest`, `DiscountValidateResponse` exported from `packages/shared/types/discount.ts`
- [ ] Local `DiscountValidateResponse` interface removed from `apps/frontend/stores/cart.ts`
- [ ] `stores/cart.ts` imports `DiscountValidateResponse` from `@thia/shared`

## Technical Notes

**New shared types** — `packages/shared/types/discount.ts`:
```ts
export interface DiscountCode {
  id: string
  code: string
  type: 'percentage' | 'fixed'
  value: number
  isActive: boolean
  expiresAt: string | null
  timesUsed: number
  usageLimit: number | null
  minOrderAmount: number
}

export interface DiscountValidateRequest {
  code: string
  subtotal?: number
}

export interface DiscountValidateResponse {
  valid: boolean
  type: 'percentage' | 'fixed'
  value: number
  message: string
  code: string
}
```

**Route file**: `apps/backend/src/routes/discount-codes/index.ts`

**Validation order**:
1. Query `discount_codes` table with `ilike('code', inputCode)` and `eq('is_active', true)`
2. Not found → `{ valid: false, message: 'Invalid discount code.' }`
3. `expires_at` check → `{ valid: false, message: 'This discount code has expired.' }`
4. `usage_limit` check → `{ valid: false, message: 'This discount code has reached its usage limit.' }`
5. `min_order_amount` check (only if `subtotal` provided) → `{ valid: false, message: 'A minimum order of X XAF is required.' }`
6. Pass → return `{ valid: true, type, value, message: 'Discount applied.', code: dc.code.toUpperCase() }`

**Frontend update**: Remove the inline `DiscountValidateResponse` interface from `stores/cart.ts` and replace with `import type { DiscountValidateResponse } from '@thia/shared'`.

**Registration**: `fastify.register(discountCodesRoutes)` in `src/app.ts`

## Dependencies
None — self-contained. Frontend update (`stores/cart.ts`) can be done alongside.
