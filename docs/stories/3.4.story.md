# Story 3.4 — NotchPay Payment Integration (Backend)

## Status
done

## Description
Implement the NotchPay payment service and its three routes: initialize a payment (returns a hosted payment URL), verify a transaction status, and handle the inbound webhook that NotchPay calls when payment completes. The webhook handler updates order status, decrements stock, and increments discount usage.

## Acceptance Criteria
- [x] `POST /payments/initialize` requires authentication; calls NotchPay API and returns `payment_url`
- [x] `POST /payments/verify` requires authentication; returns current transaction status from NotchPay
- [x] `POST /payments/webhook` requires no auth; verifies HMAC-SHA256 signature from `x-notch-signature` header
- [x] Webhook with invalid signature returns 400; does not process the payload
- [x] On `payment.complete` event: order status updated to `paid`, stock decremented for each item, discount `times_used` incremented if a code was applied
- [x] Webhook handler always returns HTTP 200 to NotchPay (even on internal errors — log and swallow)
- [x] `initializePayment()` and `verifyPayment()` implemented in `apps/backend/src/services/payment.service.ts`
- [x] Routes registered in `src/app.ts`

## Technical Notes

**Service file**: `apps/backend/src/services/payment.service.ts`

```ts
// initializePayment — calls NotchPay /v1/payments/initialize
export async function initializePayment(payload: {
  orderId: string
  amount: number        // XAF integer
  email: string
  phone: string
  channel: 'cm.mtn' | 'cm.orange'
  description: string
  callbackUrl: string
}): Promise<{ reference: string; payment_url: string }>

// verifyPayment — calls NotchPay /v1/payments/{reference}
export async function verifyPayment(
  reference: string
): Promise<{ status: string; amount: number; reference: string }>
```

**Route files**:
- `apps/backend/src/routes/payments/index.ts` — initialize + verify
- `apps/backend/src/routes/payments/webhook.ts` — webhook handler

**Webhook signature verification**:
```ts
import { createHmac } from 'crypto'
const sig = request.headers['x-notch-signature']
const expected = createHmac('sha256', env.NOTCHPAY_WEBHOOK_SECRET)
  .update(JSON.stringify(request.body))
  .digest('hex')
if (sig !== expected) throw new AppError(400, 'INVALID_SIGNATURE', '...')
```

**Webhook `payment.complete` handler**:
1. Find order by `notchpay_reference`
2. Update `orders.status = 'paid'`
3. For each `order_items` row: decrement `product_variants.stock_quantity` by `quantity`
4. If `orders.discount_code` is set: `UPDATE discount_codes SET times_used = times_used + 1`
5. Return `reply.status(200).send({ received: true })`

**Registration**: `fastify.register(paymentsRoutes)` and `fastify.register(paymentsWebhookRoutes)` in `src/app.ts`

**Environment variables used**: `NOTCHPAY_PUBLIC_KEY`, `NOTCHPAY_PRIVATE_KEY`, `NOTCHPAY_WEBHOOK_SECRET`
